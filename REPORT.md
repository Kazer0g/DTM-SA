# Distributed Text Mining and Sentiment Analysis

**Project 33 — Distributed Network Programming | Innopolis University**

A PySpark MapReduce pipeline that implements **Part C** of the project specification: combining word-frequency analysis with sentiment classification to report the **top positive and negative terms per document group**.

## Usage

### Run the full pipeline (recommended)

```bash
cd src
python runner.py \
  --input-csv ../data/test.csv \
  --output-dir ../results
```

### Run pipeline only

```bash
python run_pipeline.py \
  --input-csv ../data/test.csv \
  --output-dir ../results
```

### Run validation only

```bash
python validate.py \
  --input-csv ../data/test.csv \
  --predictions-csv ../results/predictions.csv \
  --output-json ../results/validation_results.json
```

### Run scalability benchmarks

```bash
python scalability.py \
  --input-csv ../data/test.csv \
  --output-csv ../results/scalability_results.csv \
  --doc-counts "100,500,1000" \
  --chunk-sizes "500,1000,2000"
```

### Generate dashboard

```bash
python visualize_results.py \
  --scalability-csv ../results/scalability_results.csv \
  --validation-json ../results/validation_results.json \
  --group-report-json ../results/group_term_sentiment_report.json \
  --predictions-csv ../results/predictions.csv \
  --output-png ../results/dashboard.png
```

## How It Works

The pipeline follows a two-stage MapReduce design inside a single PySpark application:

**Stage 1 — Sentiment Map.** Documents are partitioned across PySpark workers via `src/pipeline.py`. Each worker loads the pre-trained TF-IDF vectoriser and Logistic Regression model from disk, vectorises its partition, and emits `(row_id, group, text, sentiment_label)` tuples.

**Stage 2 — Term-Frequency Reduce.** Labelled records are filtered to positive/negative, tokens are exploded, and results are grouped by `(group, sentiment, term)`. A PySpark window function ranks terms within each bucket to extract the top-k entries, producing the final JSON report (`results/group_term_sentiment_report.json`).

### Model

- **Vectoriser:** `TfidfVectorizer(ngram_range=(1,2), sublinear_tf=True, stop_words="english", max_features=220000)`
- **Classifier:** `LogisticRegression(max_iter=3000, C=1.0, solver="lbfgs")`
- **Training corpus:** 114,159 samples (60,000 restaurants, 45,615 tweets, 8,544 movies), split 80/20

### Datasets

| Domain | Dataset | Rows |
|---|---|---|
| Movies | [SetFit/sst5](https://huggingface.co/datasets/SetFit/sst5) | 11,855 |
| Restaurants | [Yelp/yelp_review_full](https://huggingface.co/datasets/Yelp/yelp_review_full) | 70,000 |
| Tweets | [cardiffnlp/tweet_eval](https://huggingface.co/datasets/cardiffnlp/tweet_eval) (sentiment) | 59,900 |
| **Total** | | **141,755** |
